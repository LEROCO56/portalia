# Cómo medir si ChatGPT (y las otras IAs) recomiendan tu negocio

**Respuesta corta:** arma una matriz de 5 consultas × 5 IAs, dale a cada celda 0 (no apareces), 1 (te nombra entre otros) o 2 (te recomienda primero o te enlaza) y repítela el mismo día cada mes con el mismo protocolo. El total, sobre 50, es tu indicador de visibilidad en IA.

## ¿Por qué no basta con preguntarle una vez a ChatGPT?

Porque las respuestas cambian según la sesión, el historial, la ubicación y la versión del modelo. Una sola pregunta es una anécdota. Una matriz con protocolo fijo es un dato que puedes comparar.

## El protocolo en 5 pasos

1. **Elige 5 consultas** que haría un cliente real: 2 de categoría + lugar ("mejor spa en Chapinero"), 1 de problema, 1 de comparación y 1 de precio.
2. **Pregunta en 5 IAs:** ChatGPT con búsqueda, Claude, Gemini, Perplexity y Copilot.
3. **Usa sesión nueva o modo incógnito**, sin historial ni memoria activa.
4. **Escribe la consulta exactamente igual** cada mes.
5. **Guarda captura** de cada respuesta: es tu evidencia.

## La matriz

| Consulta | ChatGPT | Claude | Gemini | Perplexity | Copilot |
|---|---|---|---|---|---|
| Consulta 1 | 0/1/2 | | | | |
| Consulta 2 | | | | | |
| … | | | | | |

Suma todo: el máximo es 50. Anota también qué competidores aparecen y qué fuentes cita cada IA; ahí están las pistas de dónde te falta presencia.

## ¿Cada cuánto medir?

Una vez al mes, el mismo día de la semana. Las variaciones de una semana a otra no son señal; la tendencia de 60 a 90 días sí.

## ¿Qué hago con el resultado?

- **0 en todas las IAs y el Auditor Portalia por debajo de 60:** el problema es técnico. Revisa datos estructurados, `robots.txt` y preguntas frecuentes visibles.
- **Auditor alto pero 0 en las IAs:** faltan menciones externas que confirmen quién eres.
- **Apareces en Perplexity pero no en ChatGPT:** revisa qué fuentes cita ChatGPT para esa consulta y busca presencia allí.
- **Te nombran con datos viejos:** tu nombre, dirección o teléfono no coinciden entre fuentes.

## Preguntas relacionadas

**¿Hay herramientas que hagan esto automático?**
Existen herramientas de monitoreo de marca en IA, pero para un negocio pequeño la matriz manual de 25 minutos al mes es suficiente y te obliga a leer las respuestas, que es donde aparecen las ideas.

**¿Sirve preguntar "¿conoces a [mi negocio]?"?**
Poco. Esa pregunta mide si el modelo te reconoce, no si te recomienda. Tus clientes no preguntan por tu nombre; preguntan por su problema.

**¿Qué puntaje es "bueno"?**
Depende de tu categoría y ciudad. Lo importante es la dirección: si subes mes a mes, el trabajo está funcionando.
